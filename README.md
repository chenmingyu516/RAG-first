# 企业级 RAG 知识库问答系统（毕设）

基于 **LangChain** 框架开发的电商商品知识库问答系统，支持浏览器访问、多用户多会话、知识库管理、回答引用知识片段等功能。

## 一、功能清单

| 功能 | 说明 |
|---|---|
| 用户注册 / 登录 | 浏览器中注册登录，密码加密存储 |
| 修改密码 | 登录后可修改密码 |
| 多用户多会话 | 每个用户拥有独立的会话列表 |
| 历史记录 | 会话记录持久化，下次登录可找回 |
| 知识库问答 | 基于知识库内容回答，流式输出 |
| 引用来源 | 回答中显示引用的知识片段及来源文件 |
| 知识库管理 | 仅管理员可上传/删除文档 |
| 权限控制 | admin 可管理知识库，普通用户只能问答 |

管理员账号：`admin` / `123456`

## 二、技术栈

- **后端**：Python + FastAPI + LangChain + Chroma（向量库）+ SQLite
- **前端**：Vue3 + Element Plus + Vite
- **大模型**：阿里云百炼（通义千问）+ text-embedding 嵌入模型

## 三、目录结构

```

│   ├── app/
│   │   ├── rag/      # RAG 核心：嵌入、向量库、文档解析、检索问答

```

## 四、运行前准备

你需要：**Python 3.10+** 和 **Node.js 18+**（本机已装好）。

### 1. 获取阿里云百炼 API Key（免费）

1. 打开 <https://bailian.console.aliyun.com> ，用支付宝账号登录（需实名）。
2. 首次进入会引导「开通模型服务」，按提示同意开通（免费）。
3. 在页面右上角头像处找到 **API-KEY**，点击「创建我的API-KEY」，复制生成的一串以 `sk-` 开头的密钥。
4. 把密钥填到后面的 `.env` 文件中。

> 说明：新用户通常有免费额度，足够毕设演示；额度用完后充值几块钱即可。

### 2. 安装依赖

双击项目根目录的 **`setup.bat`**（自动创建后端虚拟环境、安装 Python 依赖和前端依赖，需要几分钟）。

### 3. 配置密钥

打开 `backend\.env`（若没有，就把 `backend\.env.example` 复制一份改名 `.env`），把 `DASHSCOPE_API_KEY=` 后面填上你的密钥：

```
DASHSCOPE_API_KEY=sk-你的密钥
```

## 五、启动系统

双击根目录的 **`start.bat`**，会打开两个窗口（后端 + 前端）。

然后用浏览器打开：**http://localhost:5173**

- 管理员：`admin` / `123456`
- 普通用户：先在注册页注册一个

## 六、使用流程

1. 用 `admin` 登录 → 右上角头像菜单 → **知识库管理** → 上传商品资料（支持 PDF/Word/TXT/Markdown）。
2. 注册一个普通用户登录 → 进入问答页 → 提问，回答会流式输出，并展示「参考来源」知识片段。
3. 左侧可新建/切换/删除会话，历史记录随时可找回。

> 测试数据：项目里提供了一个 `示例商品知识库.md`，可先在知识库管理页上传它来体验。

## 七、常见问题

- **问：回答报错「生成回答失败」？** 通常是 `.env` 里的 API Key 没填或填错、或没开通模型服务。
- **问：上传文档失败？** 检查文件格式是否为 PDF/Word/TXT/Markdown，文件不宜过大。
- **问：端口被占用？** 后端默认 8000，前端 5173，可在 `run.py` 和 `frontend/vite.config.js` 修改。
